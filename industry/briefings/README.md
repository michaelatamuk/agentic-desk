# Briefings

One briefing per month on the most important agentic AI news around the world, ranked by impact and
written in plain English. It is for someone who follows the industry but does not read every launch.

## How to run a month

When asked for a month:

1. Read `PROCESS.md` — it gives the numbered workflow, the five research lenses, the recall table,
   and the named outlets for the final sweep.
2. Read `FORMAT.md` — it gives the brief structure, geographic formatting, style rules and status
   vocabulary.
3. Create `YYYY-MM.md` in this folder and add it to the index below.

Run the lenses **before** reading the recall table in `PROCESS.md`. The recall table is for the
editor's coverage check only. Discovery agents must not see it — if they do, the test is rigged
and the result proves nothing.

## Definition

**Agentic AI** here means software that can plan, call tools, and take actions with some autonomy —
not a chatbot that only writes text.

A **personal agent** is an always-on agent that works for one person across apps.

A **decision model** answers typed questions (yes/no, choice, score) with probabilities instead of
writing prose.

The **agent loop** is the cycle of asking the model what to do, running the tool it names, feeding
the result back and repeating.

The **runtime** (or harness) is the software that runs that loop: sessions, sandboxes, memory,
retries and logs.
