# Orbit image sources

All images come from the public repository `ThinkFlowLab/orbit` at `d53837a` (27 November 2026). They use synthetic or sample data, not a live customer account.

The stills from `qa/` and `docs/qa/proofs/` are real UI captures from the repository's test runs. Some carry test labels or use mock app names. The GIFs are the repository's sample onboarding animations; its README says they are not recordings of live agent runs. The agent-choice crop comes from a QA gallery; the gallery header and the phone panel were removed.
