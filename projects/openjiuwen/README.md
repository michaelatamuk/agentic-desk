# openjiuwen

Issue write-ups, design proposals and the shipped surfaces.

openJiuwen is a company platform we contribute to, not a product our team owns. This folder is our
work in it. Product context, code studies and release notes are in
[`company/openjiuwen/`](../../company/openjiuwen/overview.md).

| Path | Contents |
|---|---|
| `issues/` | One file per upstream issue or pull request, grouped by component |
| `design/` | Proposals for what to build next, one folder per topic |
| `channels/` | The shipped surfaces: IDE, browser extension, JupyterLab and SDK |

Code studies are in [`company/openjiuwen/notes/`](../../company/openjiuwen/notes/); release notes are
in [`company/openjiuwen/whats-new/`](../../company/openjiuwen/whats-new/). Both describe openJiuwen,
not the work our team did.
