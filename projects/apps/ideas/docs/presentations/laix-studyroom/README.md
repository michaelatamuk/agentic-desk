# LAIX presentations — StudyRoom example

Self-contained HTML decks for presenting LAIX to managers and to PPMA/technical builders.

## Open them

Open either file in Chrome or Edge. No install, build or network is required.

```text
index.html       # product / manager deck
technical.html   # technical architecture deck
```

Keyboard:

- `←` / `→` or space — move
- `N` — speaker notes
- `F` — full screen
- `Home` / `End` — first / last slide

Print to PDF from the browser if you need a leave-behind.

## Two decks

| Deck | Audience | Length |
|---|---|---|
| `index.html` | Managers and PPMA builders | 14 slides, about 20–25 minutes |
| `technical.html` | Engineers, architects and PPMA builders | 16 slides, about 30 minutes |

Use the product deck to establish the problem and the boundary. Use the technical deck to show what is inside LAIX and how the pieces fit together.

## The order

1. **Cold open** — a room with one stuck learner.
2. **What LAIX is** — one question, seven answers.
3. **The decision receipt** — situation, options, constraints, choice, approval, record.
4. **StudyRoom** — wait, override, ask, consent, board.
5. **Manager lens** — less noise, consistent help, auditable trust.
6. **PPMA lens** — memory and permission stay with PPMA; LAIX owns the decision.
7. **Pilot** — one class, one subject, 90 days.

## Demo safety

Use the teacher wall and manual `Next` only.

The safe live path is in `speaker-notes.md`. Do not use autoplay, the alternatives drawer, or the helper-disconnect step in the current Phase 0 build.
