# openjiuwen

What the platform does, what broke in it, what shipped, and what we want next.

| Path | Contents |
|---|---|
| `issues/` | One file per upstream issue or pull request, grouped by component |
| `whats-new/` | Release notes by month, plus the slides that go with them |
| `ideas/` | Proposals that are not scheduled yet |
| `assessments/` | Analyses of how the product behaved in one concrete case |
| `operating-environment.md` | What openjiuwen is as a runtime |
| `robot-brain.md` | The robotics framing of the same platform |
| `audiences.md` | Who we are trying to reach and how they find tools |

Documents that describe the code itself — prompt assembly, plugin design, improvement RFCs — stay in
the code repository. This folder is for writing about the product for people who will not read the
source.
